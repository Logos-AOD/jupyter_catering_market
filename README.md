# Рынок общественного питания Москвы — исследовательский анализ

Инвесторы планируют открыть новое заведение общественного питания в Москве. Формат заведения пока не определён: это может быть кафе, ресторан, бар, пиццерия или кофейня. Также обсуждаются расположение, меню и ценовая категория будущего заведения.

В рамках проекта проведён исследовательский анализ рынка общественного питания Москвы на основе данных сервисов **Яндекс Карты** и **Яндекс Бизнес** за лето 2022 года.

**Цель исследования** — провести исследовательский анализ рынка общественного питания Москвы и подготовить рекомендации для инвесторов по выбору подходящего формата, места расположения и ценовой категории нового заведения.

## Задачи исследования

### Предобработка данных

1. Загрузить и объединить данные о заведениях и среднем чеке.
2. Изучить структуру данных, типы, пропуски, соответствие описанию.
3. Провести предобработку данных:
   - корректировка типов данных;
   - обработка пропущенных значений;
   - поиск и удаление дубликатов;
   - нормализация текстовых столбцов;
   - создание дополнительных признаков.
  
### Исследовательский анализ

1. Исследовать категории заведений и их количество.
2. Проанализировать распределение заведений по административным районам Москвы, отдельно — по ЦАО.
3. Изучить соотношение сетевых и несетевых заведений (в целом и по категориям).
4. Исследовать количество посадочных мест, найти аномалии и выбросы, определить типичное количество мест по категориям.
5. Проанализировать рейтинги заведений и их распределение по категориям.
6. Изучить взаимосвязь рейтинга с другими характеристиками заведения.
7. Найти наиболее популярные сети Москвы, их средние рейтинги и категории.
8. Исследовать зависимость среднего чека от района и удалённости от центра.
9. Визуализировать результаты анализа.
10. Сформулировать итоговые выводы и рекомендации для заказчика.

## Данные

### 1. `rest_info.csv` — данные о заведениях

| Столбец     | Описание                                                        |
|-------------|-----------------------------------------------------------------|
| `id`        | идентификатор заведения                                         |
| `name`      | название заведения                                              |
| `address`   | адрес заведения                                                 |
| `district`  | административный район                                          |
| `category`  | категория заведения (кафе, ресторан, кофейня и т.д.)            |
| `hours`     | дни и время работы                                              |
| `rating`    | рейтинг заведения по оценкам пользователей в Яндекс Картах     |
| `chain`     | признак сети: `0` — не сетевое, `1` — сетевое                  |
| `seats`     | количество посадочных мест                                      |

### 2. `rest_price.csv` — данные о среднем чеке

| Столбец              | Описание                                                                 |
|----------------------|--------------------------------------------------------------------------|
| `id`                 | идентификатор заведения                                                  |
| `price`              | ценовая категория («средние», «ниже среднего», «выше среднего»)          |
| `avg_bill`           | средний чек в виде диапазона строкой                                     |
| `middle_avg_bill`    | числовая оценка среднего чека (медиана диапазона)                        |
| `middle_coffee_cup`  | числовая оценка стоимости чашки капучино                                  |

> ⚠️ Данные собраны из открытых источников и сервисов Яндекс, носят справочный характер.
